# 業種ごとの見本写真

顔（ヒーロー）を選ぶとき、写真枠が空だと、その型が自分の店に合うのかが
掴めない。そこに置く実写をここに入れておく。

`node build-site.js` で `docs/art/` に写され、公開の入れ物と一緒に配られる。
**ここが元。`docs/art/` は毎回まるごと作り直されるので、そちらに置くと消える。**

ツール本体（`dist/index.html`）には焼き込まない。必要になったときだけ
置いてある場所から読む（`assets/industry-photos.js`）。

## 名前

    <業種>-1.jpg  <業種>-2.jpg  <業種>-3.jpg

業種は `assets/templates.js` の `INDUSTRIES` の `key`。

    restaurant  居酒屋・飲食      cafe    カフェ
    salon       美容室            clinic  クリニック
    builder     工務店            school  塾・教室
    shop        物販              gym     ジム
    office      士業              company 会社

1枚目がいちばん表に出る。横長で、片側に余白があるものを置く。

## 足すとき

1. ここに `<業種>-1.jpg` … を置く
2. `assets/industry-photos.js` の `INDUSTRY_PHOTOS` に1行足す

PNG や大きすぎる写真は、そのまま置かずに落としてから置く。

    node tools/photo-to-jpg.js ~/もらった.png art/gym-1.jpg

PNG のままだと1枚2〜3MB。同じ見た目で 1/10 以下になる。

**2つめを忘れると出ない。** ここに在るものと表の食い違いは
`verify-indart.js` が見ている。

## 気をつけること

- **文字を写さない。** 焼き込まれた文字はあとから直せない。
  店名や看板が小さく入るぶんは、その店の景色として通る。
- **人の顔を写さない。** 誰の見本にも使うので、写っていると使えない。
- **権利。** 自分で撮ったもの、または商用可のものだけ。
- **重さ。** 1枚100KB前後。全業種そろえても3MB弱に収まる。
  ここは本体とは別に配られるので、選んだ業種のぶんしか読まれない。
