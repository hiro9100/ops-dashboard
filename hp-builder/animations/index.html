01 / SCROLL-DRIVEN 3D

スクロールで製品が3D回転する

セクションを position:sticky で画面に固定し、そのセクション内をどこまで スクロールしたか（0→1）を回転角に変換します。上の立体はCanvasに面を1枚ずつ描いた本物の3Dで、 画像でも動画でもありません。だからどの角度で止めても輪郭が潰れず、色や質感をコードから変えられます。

実案件では手法が3つあります。① 連番画像スクラブ（Apple方式・レンダリング済み画像を36〜120枚用意して切り替え／最も高品質・容量大）、 ② Canvasソフトウェア3D（上の方式・画像不要・軽い・単純な形状向き）、 ③ three.jsで .glb を読み込む（実モデル・質感も反射も自由・要ライブラリ）。 商品写真がある案件は①、素材がない・自動生成したい場合は②、本気の製品サイトは③が向きます。
スクロール進捗を取り出す中核（この10行がすべての土台） 
// セクションのどこまでスクロールしたかを 0→1 で得る
function progress(el){
  const r = el.getBoundingClientRect();
  const total = r.height - innerHeight;      // 動ける距離
  return Math.min(1, Math.max(0, -r.top / total));
}

// 使い方：進捗をそのまま角度・移動量・不透明度に変換する
addEventListener('scroll', () => {
  const p = progress(document.querySelector('.pin'));
  target = p * Math.PI * 4;                  // 0→720°回転
}, {passive:true});

// 描画は rAF で。scroll の中で重い処理をしないのがコツ
function loop(){
  angle += (target - angle) * 0.12;          // 慣性をつけて滑らかに
  draw(angle);
  requestAnimationFrame(loop);
}

const io = new IntersectionObserver((es) => {
  es.forEach(e => {
    if(!e.isIntersecting) return;
    const d = [...e.target.parentElement.children].indexOf(e.target);
    e.target.style.transitionDelay = (d * 90) + 'ms';   // ずらして出す
    e.target.classList.add('in');
    io.unobserve(e.target);                             // 一度きり
  });
}, {threshold:.18, rootMargin:'0px 0px -8% 0px'});

05 / POINTER

マウスに反応して立体的に傾くカード

カード内でのマウス位置を rotateX / rotateY に変換。 中の要素に translateZ を付けると、奥行きが生まれて一気に「高そう」に見えます。

◆
浮かぶアイコン

translateZ(38px) で手前に飛び出させています。

✦
光沢の追従

カーソル位置に光を置くと質感が出ます。

▲
離すと戻る

transition を戻り側だけ効かせるのがコツ。

チルトのコード 
card.addEventListener('pointermove', e => {
  const r = card.getBoundingClientRect();
  const x = (e.clientX - r.left) / r.width  - .5;   // -0.5 〜 0.5
  const y = (e.clientY - r.top ) / r.height - .5;
  card.style.transition = 'none';                   // 追従中は無効に
  card.style.transform =
    `perspective(1000px) rotateY(${x*14}deg) rotateX(${-y*14}deg) translateZ(12px)`;
  card.style.setProperty('--mx', (x+.5)*100 + '%'); // 光沢の位置
  card.style.setProperty('--my', (y+.5)*100 + '%');
});
card.addEventListener('pointerleave', () => {
  card.style.transition = 'transform .5s cubic-bezier(.2,.7,.3,1)'; // 戻りだけ滑らかに
  card.style.transform = '';
});
06 / PARALLAX

奥行きが出るパララックス

レイヤーごとに動く量を変えるだけ。手前を速く、奥をゆっくり。

奥行きは、速度差でつくる

3枚のレイヤーを別々の速さで動かしています

パララックスのコード 
const box = document.querySelector('[data-plx]');
addEventListener('scroll', () => {
  const r = box.getBoundingClientRect();
  const c = (r.top + r.height/2 - innerHeight/2) / innerHeight;  // 画面中央からのズレ
  box.querySelectorAll('.layer').forEach(l => {
    l.style.transform = `translate3d(0,${c * l.dataset.speed * -260}px,0)`;
  });
}, {passive:true});

カウントアップのコード 
function countUp(el){
  const to = +el.dataset.count, dec = +(el.dataset.dec||0), dur = 1600;
  let t0;
  const step = (t) => {
    t0 ??= t;
    const p = Math.min(1, (t - t0) / dur);
    const e = 1 - Math.pow(1 - p, 3);              // ease-out-cubic
    el.textContent = (to * e).toFixed(dec) + (el.dataset.suffix||'');
    if(p < 1) requestAnimationFrame(step);
  };
  requestAnimationFrame(step);
}

08 / INTERACTION

吸い寄せられるボタン

カーソルが近づくとボタンが寄っていきます。押し心地の印象が変わる、費用対効果の高い演出です。

マグネティックボタンのコード 
const R = 90;                                   // 反応する距離
addEventListener('pointermove', e => {
  document.querySelectorAll('[data-mag]').forEach(b => {
    const r = b.getBoundingClientRect();
    const dx = e.clientX - (r.left + r.width/2);
    const dy = e.clientY - (r.top  + r.height/2);
    const d  = Math.hypot(dx, dy);
    const on = d < r.width/2 + R;
    b.style.transform  = on ? `translate(${dx*.28}px,${dy*.34}px)` : '';
    b.querySelector('.lbl').style.transform = on ? `translate(${dx*.12}px,${dy*.14}px)` : '';
  });
}, {passive:true});
